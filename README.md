# Current Projects

## EnlaceExpress

Database project focused on the implementation and validation of a shipment and corporate messaging management platform across different database engines.

The project works with:

`MySQL` `PostgreSQL` `SQL Server` `Oracle`

It also uses:

`Docker` `DBeaver` `SQL` `Database Modeling` `RBAC` `Advanced Queries`

The main objective is to maintain logical equivalence between database engines while adapting the physical implementation to the characteristics of each database system.

---

## SmartRoute

Intelligent route optimization system for distribution companies.

The project focuses on improving the organization of delivery routes by considering factors such as:

`Traffic Conditions`
`Number of Orders`
`Vehicle Capacity`
`Delivery Time Windows`

The project is part of my academic work in project formulation and software development.
